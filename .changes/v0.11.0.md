## [v0.11.0] - 2026-09-27
### Added
* Campaign Rewind: "Rewind, new shuffle" deals a fresh game, and "Rewind, same hands" replays the lost attempt's exact deal, like a one-shot's Game over
### Changed
* Web deploys build in GitHub Actions and upload to Netlify with the CLI (production from main, previews per PR), so they no longer use Netlify build minutes
* Gamora, Falcon (both printings) and Astral Projection now show the card they look at before acting on it
### Fixed
* Inspect: long "This card, this game" log lines wrap under a round-tag column instead of overlapping the next line
* Jessica Drew's "Look at the top card of any deck" now asks which deck (encounter or a player's) and shows you the card
* Campaign: rewinding an issue after a loss deals a fresh shuffle instead of the same hands and encounter deck as the lost attempt
### Engine
* New lookAt effect: shows cards to one player through an acknowledge-only choice (Done), nothing moves
### Content
* Jessica Drew (04031b): fix the "Action::" typo in her card text
### Docs
