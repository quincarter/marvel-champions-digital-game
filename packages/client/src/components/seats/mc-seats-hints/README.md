# mc-seats-hints

The row above the filters on a wide layout: "Heroes, seat N of 4" and, while a keyboard or pad is in use, each key or button
with the word for what it does (LB / RB pick the seat, X clears it, Y moves between the filters and the list, or opens the
Filters, or inspects a hero tile, by where focus is). A hint with no glyph is not shown. No events, no focus stops.

| Property | Type                                 |
| -------- | ------------------------------------ |
| `model`  | `SeatsHintsModel` (`seats.types.ts`) |
