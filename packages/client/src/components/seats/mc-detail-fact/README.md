# mc-detail-fact

A tracked caption over its words, on the hero detail panel ("OBLIGATION" over the obligation card's name). Words only.

```html
<mc-detail-fact label="Obligation" text="Financial Woes"></mc-detail-fact>
```

| Property | Type   | Notes                       |
| -------- | ------ | --------------------------- |
| `label`  | string | the caption, translated     |
| `text`   | string | the words under it, wrapped |

It takes the colour of the panel it sits on (`color: inherit`).
