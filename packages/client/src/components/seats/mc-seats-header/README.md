# mc-seats-header

The ink bar across the top of Take your seats: Back (with the Cancel glyph while a keyboard or pad is in use), the Bangers
title and the step line. The scene fits the step text to the width and drops the title under the dark mode tab with
`titleDrop` / `titleMaxRight`.

| Property | Type                                  |
| -------- | ------------------------------------- |
| `model`  | `SeatsHeaderModel` (`seats.types.ts`) |

| Event      | Detail                               |
| ---------- | ------------------------------------ |
| `mc-seats` | `{ type: "action", action: "back" }` |

Focus stop: `back`.
