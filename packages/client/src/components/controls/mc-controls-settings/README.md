# mc-controls-settings

The settings rows from the generic row elements: a choice row is `mc-segments` with a heading, a switch row is `mc-switch-row`, Hint size is `mc-volume-slider` with a heading and a live glyph preview.

| Property | Type | Meaning |
| --- | --- | --- |
| `rows` | `ControlsSettingRow[]` | The rows, already worded. |

Events: `mc-controls` `choose`, `toggle`, `hint-slide` and `hint-step`.

Needs `@mc/ui` defined.
