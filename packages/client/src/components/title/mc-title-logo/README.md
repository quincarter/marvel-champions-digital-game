# mc-title-logo

The Title logo block: the red digital-edition caption, the MARVEL CHAMPIONS wordmark and a rule.

| Property | Meaning                                              |
| -------- | ---------------------------------------------------- |
| `input`  | `TitleLogoInput`: the caption, already translated.   |
| `mode`   | `wide` or `phone` (the wordmark is 44px on a phone). |

Slots: `top-end`, the icon row, level with the caption. Events: none. The wordmark scales with the container it stands in.
