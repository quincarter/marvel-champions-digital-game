# mc-title-banner

The caution banner of the Title: an update on offer, an update waiting for a restart, saves that did not load, the old save page.

| Property | Meaning                                                            |
| -------- | ------------------------------------------------------------------ |
| `input`  | `TitleBannerInput`: heading, detail, action buttons, close button. |

Every button is a focus stop (`data-stop` = its key). Events: `mc-press` from a button. Slots: none.
