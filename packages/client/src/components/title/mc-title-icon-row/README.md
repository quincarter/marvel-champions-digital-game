# mc-title-icon-row

The Title top row: chrome icon buttons (`@mc/ui`'s `mc-icon-button`) right-aligned, 8px apart.

| Property | Meaning                                                           |
| -------- | ----------------------------------------------------------------- |
| `input`  | `TitleIconRowInput`: the buttons, left to right, each with a key. |
| `mode`   | `wide` (44px buttons) or `phone` (40px).                          |

Events: `mc-pressed` from each button (`action` is its key). Slots: none.
