# mc-title-status

One line of words on the Title: a status above the footer, or a problem at the top of the screen for a few seconds.

| Property | Meaning                                    |
| -------- | ------------------------------------------ |
| `input`  | `TitleStatusInput`: the text and its kind. |
| `kind`   | `status` or `problem` (reflected).         |

Events: none. Slots: none.
