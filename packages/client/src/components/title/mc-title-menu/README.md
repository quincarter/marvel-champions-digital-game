# mc-title-menu

The Title menu as a two-column grid of `mc-title-menu-button` rows. A full row spans both columns; a half row sits beside the next.

| Property | Meaning                              |
| -------- | ------------------------------------ |
| `input`  | `TitleMenuInput`: the rows in order. |

CSS: `--menu-gap` is the space between rows. Events: `mc-press` from each row button. Slots: none.
