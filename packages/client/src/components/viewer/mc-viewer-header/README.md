# mc-viewer-header

The ink head of the Extras viewer: the entry's title in Bangers over a red rule, and the close button (focus stop `close`).

## Properties

| Name          | Type    | Meaning                              |
| ------------- | ------- | ------------------------------------ |
| `heading`     | string  | The title, in capitals.              |
| `close-label` | string  | The close button's accessible name.  |
| `compact`     | boolean | A phone's smaller title and padding. |

## Events

`mc-viewer` `{ type: "close" }`.
