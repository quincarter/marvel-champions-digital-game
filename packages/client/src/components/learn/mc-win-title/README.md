# mc-win-title

How to win's two-line headline: ink first line, Hero Red second line.

## Usage

```ts
html`<mc-win-title first="ONE WAY TO WIN." second="TWO WAYS TO LOSE."></mc-win-title>`;
```

Size it with `--title-size` (30px).

## Properties

| Name     | Type   | Meaning                             |
| -------- | ------ | ----------------------------------- |
| `first`  | string | The first line, already translated. |
| `second` | string | The red line, already translated.   |

## Events

None.
