# mc-trophy-state

An achievement's state as a word and a mark, never colour alone: EARNED (a filled paper chip with a check mark), LOCKED (an
outline) and SOON (a dashed, dimmed outline: tracked from a future update). The chip takes the colour of the card it sits on.

| Property | Attribute | Type                              |
| -------- | --------- | --------------------------------- |
| `state`  | `state`   | `earned`, `locked` or `untracked` |
| `label`  | `label`   | string (translated)               |

No events, no stops, no slots.
