# mc-trophy-group

A pack's heading inside the Mods family: "FROM <PACK>" and how many of its achievements are earned, over a thin rule.
A label only: it does not fold or open, takes no press and is not a stop.

| Property | Type                                   |
| -------- | -------------------------------------- |
| `model`  | `TrophyGroupModel \| null` (`.types`)  |
| `label`  | string (translated, shown in capitals) |

No events, no stops, no slots. Needs `@mc/ui` defined.
