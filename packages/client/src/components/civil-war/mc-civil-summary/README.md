# mc-civil-summary

The scenario at a glance: the leader, the two stage cards, the chosen sets as pictures and the facts. A hidden item is a card back, never its face.

| Property   | Type            | Meaning           |
| ---------- | --------------- | ----------------- |
| `view`     | `BuilderView`   | The builder view. |
| `pictures` | `CivilPictures` | Pictures.         |

Events: `mc-civil-war` `inspect` to read a stage.

Needs `@mc/ui` defined.
