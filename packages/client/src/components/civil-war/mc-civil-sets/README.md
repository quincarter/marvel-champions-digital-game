# mc-civil-sets

Step 4: the counter line and the candidate modular sets in sections, each the Set up the table `mc-setup-set-tile` (stops civil:set:<id>), with a fold for the other side.

| Property   | Type              | Meaning                 |
| ---------- | ----------------- | ----------------------- |
| `modular`  | `ModularStepView` | The sections and tiles. |
| `pictures` | `CivilPictures`   | Pictures.               |
| `mode`     | attribute         | wide, tablet or phone.  |

Events: `mc-civil-war` `act` for a tile or the fold, `sheet` to open its cards.

Needs `@mc/ui` defined.
