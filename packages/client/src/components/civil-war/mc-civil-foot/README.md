# mc-civil-foot

The sticky foot: Random, Random and blind and Continue to heroes (primary). Continue is dimmed with its reason while the build has a problem, and still says why on a tap.

| Property       | Type      | Meaning                   |
| -------------- | --------- | ------------------------- |
| `start-label`  | attribute | The primary button words. |
| `start-reason` | attribute | Why it is unavailable.    |
| `can-start`    | attribute | The build can start.      |

Events: `mc-civil-war` `act` for `civil:random`, `civil:random-blind` and `civil:start`.

Needs `@mc/ui` defined.
