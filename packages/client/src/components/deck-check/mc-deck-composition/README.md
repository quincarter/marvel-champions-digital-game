# mc-deck-composition

The rail's aspect section: a heading and a segment per aspect; `anchorOf(aspect)` finds a segment for the tip plate.

Properties are declared in `mc-deck-composition.types.ts`; the element holds no game state and computes nothing. Events: the segments' own.

Registered by its parent (`import "../mc-deck-composition/mc-deck-composition"`), once. Tests: `__tests__/`.
