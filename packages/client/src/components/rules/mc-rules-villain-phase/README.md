# mc-rules-villain-phase

The Villain phase tab: the six steps in order in a scrolling list (`mc-rules-step`, which this element registers), with the rules citation under it.

## Properties

| Name       | Type               | Meaning              |
| ---------- | ------------------ | -------------------- |
| `steps`    | `RulesStepModel[]` | The steps, in order. |
| `citation` | string             | The rules citation.  |

## Events

None. `scroller` gives the list's scrolling element.
