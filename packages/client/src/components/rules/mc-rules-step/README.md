# mc-rules-step

One of the villain phase's six steps: its number and name, what happens, and the picture that illustrates it where one applies (a scheme or villain scan opens the card hover popover; the encounter card back is plain). The step the live game is on is an ink card marked "HAPPENING NOW" in words as well as by its fill. A focus stop, `row:step:<n>`; there is nothing to press.

## Properties

| Name   | Type             | Meaning                         |
| ------ | ---------------- | ------------------------------- |
| `step` | `RulesStepModel` | The step as the scene words it. |

## Events

None.
