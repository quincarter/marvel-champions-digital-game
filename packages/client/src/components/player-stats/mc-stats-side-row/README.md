# mc-stats-side-row

One villain in the Focus view's list, with its score.

## Usage

```ts
html`<mc-stats-side-row .model=${row}></mc-stats-side-row>`;
```

## Properties

| Name    | Type                         | Meaning  |
| ------- | ---------------------------- | -------- |
| `model` | StatsSideRowModel (property) | The row. |

## Events

`mc-pressed`: `{ type: "focus-row", row }`.

## Slots

None.
