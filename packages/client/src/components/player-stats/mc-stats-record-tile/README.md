# mc-stats-record-tile

The Overview's headline tile: the record, the rate, a track and the streak.

## Usage

```ts
html`<mc-stats-record-tile data-stop="tile:record" record="12–5"></mc-stats-record-tile>`;
```

## Properties

| Name                               | Type   | Meaning                   |
| ---------------------------------- | ------ | ------------------------- |
| `caption / record / rate / detail` | string | The words.                |
| `fraction`                         | number | 0 to 1: the track's fill. |
