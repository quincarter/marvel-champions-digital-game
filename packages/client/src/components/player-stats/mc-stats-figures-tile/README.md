# mc-stats-figures-tile

A caption over labelled figures.

## Usage

```ts
html`<mc-stats-figures-tile label="Each game" .lines=${lines}></mc-stats-figures-tile>`;
```

## Properties

| Name    | Type                         | Meaning                |
| ------- | ---------------------------- | ---------------------- |
| `label` | string                       | The caption.           |
| `lines` | StatsFigureLine[] (property) | Label and value pairs. |

## Events

None.

## Slots

None.
