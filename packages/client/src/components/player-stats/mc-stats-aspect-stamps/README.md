# mc-stats-aspect-stamps

A hero's aspects as stamps with the aspect's word on them and what you did with it.

## Usage

```ts
html`<mc-stats-aspect-stamps caption="ASPECTS" .aspects=${aspects}></mc-stats-aspect-stamps>`;
```

## Properties

| Name      | Type                          | Meaning     |
| --------- | ----------------------------- | ----------- |
| `caption` | string                        | The label.  |
| `aspects` | StatsAspectStamp[] (property) | The stamps. |

## Events

None.

## Slots

None.
