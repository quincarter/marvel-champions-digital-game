# mc-stats-overview

The Overview tab's tiles in a column grid; the favorite hero stands tall on a wide screen.

## Usage

```ts
html`<mc-stats-overview .tiles=${tiles}></mc-stats-overview>`;
```

## Properties

| Name    | Type                        | Meaning             |
| ------- | --------------------------- | ------------------- |
| `tiles` | StatsTileModel[] (property) | The tiles in order. |

## Events

None.

## Slots

None.
