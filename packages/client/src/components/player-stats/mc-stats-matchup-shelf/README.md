# mc-stats-matchup-shelf

One villain in the Shelves view; a press opens its Focus view.

## Usage

```ts
html`<mc-stats-matchup-shelf .shelf=${shelf}></mc-stats-matchup-shelf>`;
```

## Properties

| Name    | Type                       | Meaning    |
| ------- | -------------------------- | ---------- |
| `shelf` | StatsShelfModel (property) | The shelf. |

## Events

`mc-pressed`: `{ type: "open-focus", row }`.

## Slots

None.
