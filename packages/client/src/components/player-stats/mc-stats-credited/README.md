# mc-stats-credited

A Matchups name that keeps a custom pack's designer credit in sight: the name is cut, the credit stays whole.

## Usage

```ts
html`<mc-stats-credited label="The Rose (by PermaKarma)" .lines=${2}></mc-stats-credited>`;
```

## Properties

| Name    | Type   | Meaning                                     |
| ------- | ------ | ------------------------------------------- |
| `label` | string | The name, with (by Designer) when credited. |
| `lines` | number | The most lines the name may take (1).       |

## Events

None.

## Slots

None.
