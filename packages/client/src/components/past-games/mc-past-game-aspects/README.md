# mc-past-game-aspects

The aspect chips along the foot of a hero's picture in Past games. One chip per aspect the seat's deck used, side by side
across the picture's width, in the aspect's printed frame colour (`--mc-fill-<aspect>`, the panel layer's). Each writes the
whole name, a three-letter code or its first letter, by the room it has: a container query on every chip, so nothing is
measured. The three are always in the markup, so the name is also findable text.

| Property | Type                       |
| -------- | -------------------------- |
| `badges` | `AspectBadge[]` (`.types`) |

No events, no stops, no slots. The picture holds the press and the hover.
