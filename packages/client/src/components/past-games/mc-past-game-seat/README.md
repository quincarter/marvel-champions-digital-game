# mc-past-game-seat

One seat of a game in the details: the hero's name and whether it fell (the heading), then its damage and thwart, the deck
it played and the three cards it played most. The scene words every line; the element only sets them.

| Property | Type                                   |
| -------- | -------------------------------------- |
| `model`  | `PastGameSeatModel \| null` (`.types`) |

No events, no stops, no slots.
