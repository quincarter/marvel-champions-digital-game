# mc-side-story-stage

The reading area and the line under it ("PAGE 2 · PANEL 3"). The comic picture is drawn in the canvas (its camera pans and masks animate every frame), so the reading area is an empty box: `readingArea` is what the scene measures, leaves a hole at, and shows the picture through.

## Properties

| Name    | Type   | Meaning                                      |
| ------- | ------ | -------------------------------------------- |
| `where` | string | The page and panel line, already translated. |

## Events

None.
