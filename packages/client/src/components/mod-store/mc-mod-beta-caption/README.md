# mc-mod-beta-caption

The comic narration box above the tabs saying why the store is in beta: a caution yellow box, an ink border and a hard offset shadow. Presentational, no events.

Properties are declared in `mc-mod-beta-caption.types.ts`; the element holds no game state and computes nothing. Registered by its parent (`import ".../mc-mod-beta-caption/mc-mod-beta-caption.js"`), once. Tests: `__tests__/`.
