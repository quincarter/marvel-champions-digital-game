# mc-pack-title

A pack page's title block: the name in display type, the byline, the meta line and the state chip (`mc-pack-state-chip`).

Properties are declared in `mc-pack-title.types.ts`; the element holds no game state and computes nothing. Registered by its parent (`import ".../mc-pack-title/mc-pack-title.js"`), once. Tests: `__tests__/`.
