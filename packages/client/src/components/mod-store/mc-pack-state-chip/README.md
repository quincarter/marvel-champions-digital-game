# mc-pack-state-chip

A pack's state as a mark and words (never colour alone); the call to action is the red one.

Properties are declared in `mc-pack-state-chip.types.ts`; the element holds no game state and computes nothing. Registered by its parent (`import ".../mc-pack-state-chip/mc-pack-state-chip.js"`), once. Tests: `__tests__/`.
