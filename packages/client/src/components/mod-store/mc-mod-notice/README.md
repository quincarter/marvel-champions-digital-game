# mc-mod-notice

The first-run heads-up about mods over a dimmed store: Deadpool and Spider-Man with round portraits and speech bubbles, and Report a problem / Got it. The backdrop takes every press. Events: `mc-mod-store` `{ type: "notice", answer }`.

Properties are declared in `mc-mod-notice.types.ts`; the element holds no game state and computes nothing. Registered by its parent (`import ".../mc-mod-notice/mc-mod-notice.js"`), once. Tests: `__tests__/`.
