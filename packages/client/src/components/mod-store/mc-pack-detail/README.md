# mc-pack-detail

One pack's page: the pictures, title, text, gallery, status line and buttons in a flex column; the text sits beside the pictures on a wide screen and under them on a phone.

Properties are declared in `mc-pack-detail.types.ts`; the element holds no game state and computes nothing. Registered by its parent (`import ".../mc-pack-detail/mc-pack-detail.js"`), once. Tests: `__tests__/`.
