# mc-pack-text

The scrolling text of a pack's page in a parchment box. Native scrolling; the place is kept by `listId`.

Properties are declared in `mc-pack-text.types.ts`; the element holds no game state and computes nothing. Registered by its parent (`import ".../mc-pack-text/mc-pack-text.js"`), once. Tests: `__tests__/`.
