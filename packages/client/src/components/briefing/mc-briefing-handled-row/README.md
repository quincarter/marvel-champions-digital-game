# Briefing handled row

`<mc-briefing-handled-row>`

One thing setup did for the player: a green check when it happens this issue or a blue arrow for a value held for a later one, its title, an optional detail line and the printed page it comes from at the right edge.

## Usage

```html
<mc-briefing-handled-row></mc-briefing-handled-row>
```

## Properties

| Name  | Kind     | What it is                                              |
| ----- | -------- | ------------------------------------------------------- |
| `row` | property | `HandledRow`, its words already in the player language. |

## Events

- none

## Files

- `McBriefingHandledRow.ts`: the class
- `mc-briefing-handled-row.ts`: the define file (registers the element once)
- `mc-briefing-handled-row.styles.ts`: the constructible stylesheet
- `mc-briefing-handled-row.types.ts`: the property and event types
- `__tests__/`: the tests
