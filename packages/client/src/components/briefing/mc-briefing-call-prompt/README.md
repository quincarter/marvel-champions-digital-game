# Briefing call prompt

`<mc-briefing-call-prompt>`

What a plain pick says about its question: who is deciding (a decision for the whole table is labelled as that), the box plain words and the printed rule under its own label.

## Usage

```html
<mc-briefing-call-prompt></mc-briefing-call-prompt>
```

## Properties

| Name    | Kind     | What it is         |
| ------- | -------- | ------------------ |
| `model` | property | `CallPromptModel`. |

## Events

- none

## Files

- `McBriefingCallPrompt.ts`: the class

- `mc-briefing-call-prompt.styles.ts`: the constructible stylesheet
- `mc-briefing-call-prompt.types.ts`: the property and event types
- `__tests__/`: the tests
