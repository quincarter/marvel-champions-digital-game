# Briefing pool

`<mc-briefing-pool>`

"From the pool": one row per resolved pool card this issue setup reads back, or for the box finale one group per destination (a stack on a phone, a grid of boxed groups on a wide column). It fills the wide left column, where "Handled for you" moves right.

## Usage

```html
<mc-briefing-pool></mc-briefing-pool>
```

## Properties

| Name | Kind | What it is |
| ---- | ---- | ---------- |
| `model` | property | `PoolModel`. |
| `phone` | attribute | The stacked groups. |

## Events

- none

## Files

- `McBriefingPool.ts`: the class
- `mc-briefing-pool.ts`: the define file (registers the element once)
- `mc-briefing-pool.styles.ts`: the constructible stylesheet
- `mc-briefing-pool.types.ts`: the property and event types
- `__tests__/`: the tests
