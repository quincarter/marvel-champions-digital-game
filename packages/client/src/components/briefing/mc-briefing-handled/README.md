# Briefing handled for you

`<mc-briefing-handled>`

"Handled for you": one framed list of what setup did automatically, under the section heading. While the issue waits on a call, or is still composing, a line saying so stands in for the list.

## Usage

```html
<mc-briefing-handled></mc-briefing-handled>
```

## Properties

| Name | Kind | What it is |
| ---- | ---- | ---------- |
| `model` | property | `HandledModel`. |

## Events

- none
