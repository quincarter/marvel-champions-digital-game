# Briefing call head

`<mc-briefing-call-head>`

What every call opens with: the "YOUR CALL" heading, the red line saying why Open issue waits, and the seat header of a per-seat call.

## Usage

```html
<mc-briefing-call-head></mc-briefing-call-head>
```

## Properties

| Name | Kind | What it is |
| ---- | ---- | ---------- |
| `model` | property | `CallHeadModel`. |

## Events

- none
