# Briefing role-building confirm card

`<mc-briefing-role-build-card>`

Role-building confirm step: the card picture beside its name, cost, why it is recommended and what taking it does. Only Confirm (the bar under it) records the card.

## Usage

```html
<mc-briefing-role-build-card></mc-briefing-role-build-card>
```

## Properties

| Name | Kind | What it is |
| ---- | ---- | ---------- |
| `model` | property | `RoleBuildCardModel`. |

## Events

- none
