# Briefing seat header

`<mc-briefing-seat-header>`

The seat hero above its prompt: the roster portrait in a 3px ink frame, "SEAT 1 · COLOSSUS" in Bangers and the deck aspect chips under the name.

## Usage

```html
<mc-briefing-seat-header></mc-briefing-seat-header>
```

## Properties

| Name | Kind | What it is |
| ---- | ---- | ---------- |
| `model` | property | `SeatHeaderModel`. |
| `phone` | attribute | A 56px portrait instead of 64px. |

## Events

- none

## Files

- `McBriefingSeatHeader.ts`: the class
- `mc-briefing-seat-header.ts`: the define file (registers the element once)
- `mc-briefing-seat-header.styles.ts`: the constructible stylesheet
- `mc-briefing-seat-header.types.ts`: the property and event types
- `__tests__/`: the tests
