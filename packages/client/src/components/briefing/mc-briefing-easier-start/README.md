# Briefing easier start

`<mc-briefing-easier-start>`

The easier-start toggle (Age of Apocalypse issue #3) as the setup screen option card: one framed card that is the whole button, the 4px red frame while on, its name and one short line of state. Focus stop `easier-start`.

## Usage

```html
<mc-briefing-easier-start></mc-briefing-easier-start>
```

## Properties

| Name | Kind | What it is |
| ---- | ---- | ---------- |
| `on` | attribute | The toggle is on. |

## Events

- `mc-briefing`: `{ type: "toggle-easier" }`.

## Files

- `McBriefingEasierStart.ts`: the class
- `mc-briefing-easier-start.ts`: the define file (registers the element once)
- `mc-briefing-easier-start.styles.ts`: the constructible stylesheet
- `mc-briefing-easier-start.types.ts`: the property and event types
- `__tests__/`: the tests
