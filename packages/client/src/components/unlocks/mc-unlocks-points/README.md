# mc-unlocks-points

The champion points line at the top of Settings > Unlocks: a heading and a line of detail. Read-only text.

| Property  | Type      | Meaning            |
| --------- | --------- | ------------------ |
| `heading` | attribute | The points line.   |
| `detail`  | attribute | The line under it. |

Needs `@mc/ui` defined.
