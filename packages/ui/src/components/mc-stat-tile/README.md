# mc-stat-tile

One boxed count ("Events 14"). Put several in a flex row (`mc-stat-tiles` does) and they share the width equally.

```html
<mc-stat-tile text="Events 14"></mc-stat-tile>
```

| Property | Attribute | Type   | Meaning                           |
| -------- | --------- | ------ | --------------------------------- |
| `text`   | `text`    | string | The words in the box (translated) |

No events. Used by `mc-stat-tiles`, the deck check summary and, later, the Decks Stats tab.
