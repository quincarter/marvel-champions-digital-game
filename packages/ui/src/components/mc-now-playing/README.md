# mc-now-playing

The ink strip at the head of the music player.

Used by `mc-music-player`.

## Markup

```html
<mc-now-playing></mc-now-playing>
```

## Properties

| Property | Type             | Notes |
| -------- | ---------------- | ----- |
| `model`  | `NowPlayingModel | null` | status, title, detail |

## Events

None.

## Files

`mc-now-playing.ts` defines the element (guarded), `McNowPlaying.ts` is the class, `mc-now-playing.styles.ts` its `css`, `mc-now-playing.types.ts` the model and event types.
