# v0.51.0: Straight to the App 🔗

Game links now open the game you have installed.

📱 **Android**: a link to marvel.champions-digital-game.com, like a shared replay, opens the app instead of the browser.
💻 **Desktop**: a shared replay opened in a desktop browser offers **Open in the desktop app**, and a link clicked while the game is open goes to that game, with no second window. Links start opening the app once v0.51.0 is installed.
📚 **The Saga**: a campaign won with an adjusted game (Manual adjust, or an Undo past a reveal) now shows an ADJUSTED stamp, and the next volume says why it's still sealed and how to open it.
🍎 **iPhone**: the game no longer gets stuck loading after iOS reloads the tab, and uses less memory so that happens less often. If your saves can't be read, the Title says so with a Reload button.
🌐 **The website**: the home, download stats and releases pages share one top bar and open on hero art.

Thank you, bktanner, for the Saga report, and GarethMagis, for the iPhone report!

# v0.51.0: Directo a la app 🔗

Los enlaces del juego ahora abren el juego que tienes instalado.

📱 **Android**: un enlace a marvel.champions-digital-game.com, como una repetición compartida, abre la app en vez del navegador.
💻 **Escritorio**: una repetición compartida abierta en un navegador de escritorio ofrece **Open in the desktop app**, y un enlace pulsado con el juego abierto va a ese juego, sin una segunda ventana. Los enlaces empiezan a abrir la app cuando tengas v0.51.0 instalada.
📚 **La Saga**: una campaña ganada con una partida ajustada (Manual adjust, o un Undo más allá de una carta revelada) ahora muestra el sello ADJUSTED, y el siguiente volumen dice por qué sigue sellado y cómo abrirlo.
🍎 **iPhone**: el juego ya no se queda cargando después de que iOS recarga la pestaña, y usa menos memoria para que eso pase menos. Si tus partidas guardadas no se pueden leer, el Title lo dice con un botón Reload.
🌐 **El sitio web**: las páginas de inicio, de estadísticas de descargas y de versiones comparten una sola barra superior y se abren sobre arte de héroes.

¡Gracias, bktanner, por el reporte de la Saga, y GarethMagis, por el reporte del iPhone!
