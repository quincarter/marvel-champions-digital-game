## Retrocede un número de campaña

¿Perdiste un número? Rewind reparte una partida nueva o repite exactamente las mismas manos, y los despliegues web pasan a GitHub Actions.

## [v0.11.0] - 2026-09-27
### Added
* Campaign Rewind: "Rewind, new shuffle" reparte una partida nueva, y "Rewind, same hands" repite el reparto exacto del intento perdido, como el Game over de una partida individual
### Changed
* Los despliegues web se compilan en GitHub Actions y se suben a Netlify con la CLI (producción desde main, vistas previas por PR), así que ya no usan minutos de compilación de Netlify
* Gamora, Falcon (ambas ediciones) y Astral Projection ahora muestran la carta que miran antes de actuar sobre ella
### Fixed
* Inspect: las líneas largas de "This card, this game" se ajustan bajo una columna de etiqueta de ronda en lugar de superponerse con la línea siguiente
* El "Look at the top card of any deck" de Jessica Drew ahora pregunta qué mazo (el de encuentros o el de un jugador) y te muestra la carta
* Campaña: retroceder un número después de una derrota reparte una baraja nueva en lugar de las mismas manos y el mismo mazo de encuentros del intento perdido
### Engine
* Nuevo efecto lookAt: muestra cartas a un jugador mediante una elección que solo se confirma (Done); nada se mueve
### Content
* Jessica Drew (04031b): se corrige el error de escritura "Action::" en el texto de su carta
### Docs
* El README muestra la insignia de estado de despliegue de Netlify
