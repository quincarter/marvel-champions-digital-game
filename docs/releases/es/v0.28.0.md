## Gracias, en las notas

Cada versión ahora agradece a las personas que reportaron o escribieron sus cambios, y el README recibe un muro de Special thanks.

## [v0.28.0] - 2026-10-19

### Added

- Las notas de cada versión agradecen a los usuarios de GitHub que reportaron o escribieron sus cambios, y el README tiene listas de Special thanks con el avatar de todos (#268).

### Changed

- El selector de asientos del roster de campaña lista primero a los cinco compañeros recomendados, el mejor primero (incluido el asiento 1), luego a todos los héroes disponibles de la A a la Z, y después a los héroes bloqueados o ya sentados de la A a la Z bajo su propio encabezado.

### Fixed

- El nombre de un héroe, su nota de mazo y su motivo ya no se quedan en blanco en el selector de asientos del roster de campaña después de que un dedo toque su fila (#272).
- Un deslizamiento lateral sobre una fila de una lista con desplazamiento ya no elige esa fila.
- El enlace de reporte de errores dentro del juego ahora rellena solo una casilla Game details, así que las ediciones en el formulario Bug report de GitHub se conservan y la casilla de captura vuelve a aceptar imágenes (#273).

### Docs

- Una página Rules authority da el orden en que ganan las fuentes de reglas cuando no coinciden, cómo se resuelven los conflictos, y enlaza todas las versiones de la Referencia de Reglas y las páginas de resoluciones de FFG.
