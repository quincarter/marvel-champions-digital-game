RULES OF USE
Bangers is never set below 12px and never used for a sentence — it is a sign painter, not a narrator.
Public Sans carries every weight of meaning at 800 (labels), 700 (emphasis), 400 (body). No 500/600 in product UI.
Numbers that change during play are Bangers so they read across a table; numbers in specs are Mono.
Minimum sizes
Phone body 10 · phone label 8 · desktop body 11. Touch target 44px on phone, 52px for the primary CTA.

Three hues that exist nowhere else in the system, so a status can never be mistaken for a cost, a warning, or an action. All three keep the 3px ink border and Bangers lettering with a 2px ink offset — they read as stamped-on markers rather than UI chrome.

06 DESIGN DECISIONS The rules that settle arguments
ONE RED PER SCREEN
Hero Red marks the single thing that moves the session forward — Continue, Choose heroes, Start game, End turn. The live round chip is the one exception, because it answers "whose clock is running".
Consequence: alarm is yellow, not red
BORDERS, NOT SHADOWS
3px ink = a real object (screen, card, CTA). 2.5px = a control inside one. 2px = a detail box inside that. Dashed = a slot that isn't filled. This is the entire depth model.
Consequence: no elevation tokens
DIM, DON'T HIDE
Illegal choices stay in place at 35–42% opacity. The board must never reflow while the player is deciding, because their hand is already moving toward a card.
Consequence: no empty-state shuffles
STATUS OWNS A BUTTON
Every status token has one concrete UI consequence: Stunned greys Attack, Confused greys Thwart, Tough hatches the HP bar. If a new status can't name the control it changes, it isn't a status — it's a modifier and belongs in the inspect sheet.
Consequence: statuses never stack silently
THUMB PARKS THE ACTION
On phone the action bar is fixed to the bottom on an ink ground: abilities row (44px) above, commit row (52px) below. Content scrolls under it; the bar never scrolls away, and its contents never reorder between screens.
Consequence: zone tabs, not a long table
NUMBERS BEFORE PROSE
Anything the player recalculates each round is a Bangers numeral at 17px+. Rules text is capped at two lines on the table; full wording is one tap away in inspect. The table is a dashboard, not a rulebook.
Consequence: inspect overlay is mandatory
